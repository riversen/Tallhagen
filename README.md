# Tallhagen

Support and privacy pages for Tallhagen, an original Norwegian math game for iPad (ages 6–8). GitHub Pages serves them from the `docs` folder:

- Support: https://riversen.github.io/Tallhagen/support.html
- Privacy policy: https://riversen.github.io/Tallhagen/privacy.html

The App Store listing uses these two addresses, and the app shows the privacy policy address under Innstillinger. Keep both pages at these addresses for as long as the app is on the App Store; when the policy changes, update its date.
